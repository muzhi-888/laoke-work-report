# 周报月报模板库

本文件是 SKILL.md 第五节模板的完整版，含字段说明，方便按需取用。

## 1. 周报模板（标准）

字段顺序：核心贡献 → 关键数据 → 工作明细(类目) → 下周计划 → 需支持 → 待补充。

**核心贡献**一句话结构：`本周主线是【把 X 从 A 推到 B】，核心产出【可量化结果】，卡点【Y】已用【Z】解除。`

**关键数据表**列：指标 | 本周 | 上周 | 环比 | 说明。无上周值则「上周」留空、环比标待补。

**工作明细**按类目分二级标题，每条格式：`动作（结果）(星期)`。

**下周计划**用 `- [ ]`，压到 ≤3 条可落地，多了进「进行中」。

**需支持**写具体决策项 + deadline + 不选的后果，禁止「需要支持」四字。

**待补充**列所有缺口，不脑补。

## 2. 月报模板（标准）

字段顺序：一句话总结 → 目标完成度表 → TOP5 成果 → 工作分布 → 问题风险 → 下月重点 → 数据缺口。

**目标完成度表**列：月初目标 | 目标值 | 实际 | 完成率 | 偏差说明。完成率 = 实际/目标。

**TOP5 成果**按影响力降序，每条带数据。

**工作分布**用类目占比表，占比来自工时或事项数估算，标注估算口径。

**问题风险**每条：`风险 | 概率 | 影响 | 当前缓解 | 需支持`。

## 3. 双周报模板

同周报，但核心贡献写「两周主线」，数据表带「上两周」对比。适合双周迭代团队。

## 4. 项目阶段汇报模板

字段：当前进度% → 本阶段交付(状态) → 核心成果数据 → 最大风险 → 需决策。

进度%后括注「按期/超前/滞后」。交付物标状态：已完成/进行中(N%)/未启动。

## 5. 站会汇总模板（日更）

极简：`昨日完成 | 今日计划 | 阻塞`。3 行，不展开。适合把每日站会消息汇总成周报素材。

## 6. 个人复盘模板（季度/半年度）

字段：目标回顾 → 关键成果 → 能力成长 → 不足与改进 → 下阶段重心。偏成长叙事，数据仍要带。

## 取用规则

- 不知道选哪个：默认周报/月报标准模板。
- 老板只看结果：强化「关键数据」和「核心贡献」，压缩明细。
- 跨周合成月报：先抽每份周报核心贡献与数据，去重合并，交叉校验数字冲突。
