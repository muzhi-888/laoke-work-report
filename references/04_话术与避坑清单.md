# 话术与避坑清单

## 一、话术改写库（before → after）

1. 「参加了需求评审」→「评审通过对齐 3 项需求边界，避免返工约 8h」
2. 「跟客户沟通了」→「完成客户 A 需求对齐，进入报价阶段（预计 5w）」
3. 「优化了流程」→「把报价流程从 2 天压到 4h，月度释放约 12h」
4. 「处理了客诉」→「闭环 2 起客诉（物流破损），补偿方案固化进 SOP」
5. 「写了文档」→「沉淀 2 份 SOP，覆盖新人高频问题」
6. 「推进了项目」→「项目 X 进度 60%（按期），v2.3 上线覆盖 3 模块」
7. 「学习了新工具」→「掌握自动化脚本，周报整理耗时 1h→5min」
8. 「支持了同事」→「支援产线缺口，补位 3 人日，保住交付节点」
9. 「分析了数据」→「定位流失主因在首单体验，建议改落地页（转化+5%）」
10. 「需要领导支持」→「需周三前拍板是否加 1 人，不加则上线延 2 周」

## 二、六大常见坑

- **流水账**：按周一~周五四列 = 流水账。改：按类目，时间只括注。
- **只写动作不写结果**：「参加评审」缺结论。改：动作+结果。
- **报喜不报忧**：风险藏着更糟。改：写清概率和影响，显专业。
- **数字打架**：周报成单 12，月报加总 50 对不上。改：合成时交叉校验。
- **过度美化**：「跟进中」写成「基本拿下」。改：状态词准确。
- **求 helping 太虚**：「希望领导多关注」。改：具体决策+deadline+后果。

## 三、状态词分级（不许越级）

```
意向 < 报价 < 合同 < 回款 < 续费
进行中(N%) < 已完成 < 验收
```
写汇报时严格用当前真实状态，不跳级。

## 四、脱敏规则

- 客户实名 → 客户 A/B/C
- 合同金额 → 金额区间（如「5w 级」），除非授权明写
- 内部组织/人事变动 → 不写具体人名，写角色
- 竞品名称 → 竞品 X，除非公开材料

## 五、自检口诀

「一核二数三分类，四周五决六脱敏」：
一句话核心贡献、带数据、按类目、下周≤3、需支持具体、敏感脱敏。

## 六、老板视角检查

写完问自己：老板看 10 秒能答出——「这人这周期牛在哪？卡在哪？要我批啥？」答不出就重写核心贡献段。
