# 周报月报工作汇报生成器（laoke-work-report）

> 局内人·老K · 专注实体老板 / 职场人 AI 落地实战

把零散的工作记录、待办、会议纪要与进度数据，一键整理成结构清晰、有重点有数据的周报、月报和汇报材料。不编造成果，只把你已经做的事说清楚。

## 这个工具解决什么

- 工作散落各处、写汇报时不知道写啥 → 你扔原始记录，我来归类、量化、提炼、排版。
- 流水账式罗列、老板看不出价值 → 固定五步法（采集→量化→提炼→排版→自检），按类目不按时间。
- 月报翻聊天翻到眼瞎 → 多份周报一键合成月报，自动交叉校验数字冲突。
- 数字前后矛盾、状态词错位 → 量化手册 + 状态分级 + 自检清单兜底。

## 核心能力

- 周报 / 月报 / 双周报 / 季度小结 / 项目阶段汇报 / 站会汇总 全套模板
- 五步成稿法 + 分岗位定制（销售/研发/运营/职能/管理）
- 量化指标手册（各岗位必带指标与算法，强制带环比）
- 话术改写库（10 组 before→after，汇报质感立刻不一样）
- 配套脚本 `scripts/report_from_log.py`：把 commit / 工作日志按类目自动归类并统计，纯标准库零依赖
- 合规护栏：不编业绩、不美化、缺口标待补、敏感信息默认脱敏

## 快速开始

```bash
# 用内置示例跑一遍（自检）
python scripts/report_from_log.py --demo

# 从文件读工作记录，生成周报草稿
python scripts/report_from_log.py --input my_log.txt --title "工作周报（2026-09-第1周）"
```

把原始记录（哪怕流水账）丢给支持 SKILL.md 的 Agent（WorkBuddy / SkillHub / Claude Code / Cursor），它会自动走五步法产出结构化汇报。
